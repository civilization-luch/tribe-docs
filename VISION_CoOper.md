# CoOper — Платформа для кооперативов

*Продукт экосистемы Tribe.*

---

## Концепция

CoOper — это платформа для создания и управления кооперативами. Люди объединяются для совместных закупок, ведения хозяйства, управления активами и внутренней экономики. Каждый участник имеет долю и голос.

## Проблема

Кооперативы — эффективная форма объединения, но администрирование ложится на плечи активистов. Сбор взносов, учёт долей, закупки, расчёты между участниками — всё вручную. Нет инструментов для прозрачного управления и масштабирования.

## Примеры

- **Потребительский кооператив** — совместные закупки продуктов/товаров со скидкой
- **Сельскохозяйственный кооператив** — общая техника, сбыт урожая
- **Жилищный кооператив** — покупка и содержание жилья сообща
- **Кредитный кооператив** — взаимопомощь, займы между участниками
- **Многофункциональный** — объединяет несколько направлений

## Модули

### Базовые

| Модуль | Назначение |
|---|---|
| **Membership** | Пайщики, участники, заявки, доли |
| **Registry** | Реестр пайщиков, учёт долей, история взносов |
| **Billing** | Паевые взносы, членские платежи, сплит закупок |
| **Treasury** | Казна, фонды, бюджеты, прозрачность |
| **Proposals** | Голосования: закупки, распределение прибыли, правила |
| **Tasks** | Закупки, дежурства, распределение товаров |
| **Content** | Новости, каталог закупок, обсуждения |

### Сервисы (монетизация)

| Модуль | Назначение |
|---|---|
| **Marketplace** | Товары и услуги внутри кооператива и для внешних |
| **Revenue** | Распределение доходов между пайщиками |

## Модель участников

| Тип | Описание | Голос |
|---|---|---|
| **Пайщик** | Внёс пай, имеет долю | Да (1 чел = 1 голос) |
| **Участник** | Пользуется услугами, не внёс пай | Ограниченный |
| **Ассоциированный член** | Внешний поставщик/партнёр | Нет |
| **Правление** | Избранные управляющие | Коллегиальное решение |

## Экономика

### Доходы

| Сервис | Суть |
|---|---|
| Вступительные паи | Единоразовый взнос при вступлении |
| Членские взносы | Регулярные платежи на содержание |
| Совместные закупки | Экономия за счёт опта |
| Реализация продукции | Продажа товаров/услуг членов кооператива |
| Услуги внешним | Комиссия за доступ к marketplace |

### Распределение доходов

| Сервис | Пайщикам | В фонды кооператива |
|---|---|---|
| Экономия на закупках | **70%** (пропорционально закупкам) | **30%** |
| Прибыль от внешних продаж | **50%** | **50%** |
| Услуги между пайщиками | **90%** исполнителю | **10%** |

## Архитектура

```
Tribe
  ├── CoLive (коливинги)
  ├── CoSpace (пространства)
  ├── CoSettle (поселения)
  ├── CoGuild (гильдии)
  └── CoOper (кооперативы)
```

## Связь с другими продуктами

CoOper может работать как самостоятельный продукт или как финансовый слой для других продуктов Tribe:

- **CoLive + CoOper** — жильцы коливинга создают потребительский кооператив для закупок
- **CoSettle + CoOper** — поселение оформлено как кооператив с паями на землю
- **CoGuild + CoOper** — участники гильдии создают кооператив для распределения доходов от проектов
- **CoSpace + CoOper** — пространство управляется как кооператив инструкторов
