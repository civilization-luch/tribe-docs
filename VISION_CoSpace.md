# CoSpace — Платформа для совместных пространств

*Продукт экосистемы Tribe.*

---

## Концепция

CoSpace — это платформа, которая превращает обычную аренду залов в самоорганизующееся пространство. Профессионалы и участники сообщества совместно используют пространство: проводят классы, мероприятия, личные практики — всё через единую систему расписания, платежей и управления.

## Проблема

Владельцы студий и пространств недозагружены: зал стоит пустым большую часть дня. Инструкторы тратят время на поиск площадок, координацию и сбор платежей. Участники не имеют единого окна, где видно расписание, цены, отзывы.

- Пространства простаивают
- Инструкторам нужна простая аренда «под ключ»
- Нет единого календаря и бронирования
- Сбор платежей — вручную
- Нет инструментов для сообщества (отзывы, рейтинг, мероприятия)

## Пример: Yoga Lab

Пространство, где работает несколько инструкторов и есть сообщество участников:

- **Инструкторы** арендуют зал для платных классов (йога, медитация, breathwork)
- **Участники** ходят по абонементу или разово
- **Личная практика** — свободное время зала для членов сообщества
- **Мероприятия** — воркшопы, ретриты, лекции, кинопоказы

То же применимо к: танцевальным студиям, коворкингам, лекториям, арт-пространствам.

## Модули

### Базовые

| Модуль | Назначение |
|---|---|
| **Membership** | Участники, инструкторы, гости, статусы, заявки |
| **Schedule** | Расписание классов и событий, календарь, повторяющиеся события |
| **Bookings** | Бронь залов под классы / личную практику / мероприятия |
| **Billing / Subscriptions** | Абонементы, разовые билеты, сплит аренды между инструкторами |
| **Treasury** | Арендный фонд, бюджеты на инвентарь и мероприятия |
| **Content** | Афиша, анонсы классов, отзывы, обсуждения |
| **Proposals** | Голосования по общим вопросам (закупка ковриков, ремонт, правила) |
| **Reputation** | Рейтинг инструкторов и участников |
| **Documents** | Договоры аренды, waivers (расписки), правила пространства |

### Сервисы (монетизация)

| Модуль | Назначение |
|---|---|
| **Marketplace** | Услуги инструкторов, аренда залов внешним |
| **LMS** | Онлайн-курсы, вебинары от инструкторов |
| **Revenue** | Распределение дохода между участниками |

## Модель участников

| Тип | Описание | Голос | Платежи |
|---|---|---|---|
| **Инструктор** | Ведёт классы, арендует пространство | Да | Аренда зала + % с билетов |
| **Участник сообщества** | Ходит на классы по подписке | Да | Абонемент / разовые билеты |
| **Гость** | Разовое посещение | Нет | Разовый билет |
| **Админ пространства** | Управляет расписанием, бюджетом | Вето | — |
| **Кандидат** | Подал заявку на вступление | Нет | — |

## Процесс приёма

```
Заявка (участник / инструктор) → Одобрение админа → Доступ к расписанию и бронированию
```

## Экономика пространства

### Доходы

| Сервис | Суть |
|---|---|
| **Классы инструкторов** | Инструктор проводит класс, продаёт билеты через платформу |
| **Абонементы участников** | Подписка на N классов в месяц |
| **Аренда залов внешним** | Пространство сдаётся сторонним арендаторам |
| **Мероприятия** | Билеты на воркшопы, лекции, ивенты |
| **Личная практика** | Члены сообщества бронируют зал для себя |

### Распределение доходов

| Сервис | Кому | В казну пространства |
|---|---|---|
| Класс инструктора | Инструктору — **70%** | **30%** |
| Абонемент участника | Инструкторам (пропорционально часам) — **70%** | **30%** |
| Аренда зала внешним | — (актив пространства) | **100%** |
| Мероприятие | Организатору — **60%** | **40%** |
| Личная практика | — | **100%** (членский доступ) |

Часть средств из казны пространства может распределяться среди активных участников по взвешенной доле участия (аналогично CoLive).

## Архитектура продукта

```
Tribe
  ├── CoLive (коливинги)
  ├── CoSpace (пространства)
  └── CoOper (кооперативы)
```

## Архитектура сообщества

```
CoSpace "Yoga Lab" [сообщество]
  │
  ├── Инструкторы (группа)
  ├── Участники сообщества (группа)
  ├── Расписание классов (Schedule)
  ├── Календарь бронирования залов (Bookings)
  └── Казна (Treasury)
```
