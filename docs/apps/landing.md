# Tribe Landing (SPA)

Маркетинговый сайт платформы. Презентует продукты, привлекает сообщества, ведёт к регистрации.

## Разделы

### 1. Главная

- Краткое позиционирование: конструктор самоуправляемых сообществ
- Сквозной пример: как сообщество проходит путь от создания до самоуправления
- CTA: «Создать сообщество»

### 2. Продукты (пресеты)

Карточки каждого Co* продукта:

| Раздел | Контент |
|---|---|
| **CoLive** | Для коливингов: управление домом, платежи, мероприятия |
| **CoSpace** | Для пространств: расписание, бронь залов, абонементы |
| **CoSettle** | Для поселений: покупка земли, паи, инфраструктура |
| **CoGuild** | Для тематических сообществ: курсы, проекты, менторство |
| **CoOper** | Для кооперативов: закупки, паи, распределение прибыли |

Каждая карточка: описание + модули + пример сообщества + ссылка на подробнее.

### 3. Как это работает

- Выбираешь тип сообщества (пресет)
- Настраиваешь модули
- Приглашаешь участников
- Сообщество самоорганизуется

### 4. Цены

- **Community** — базовые модули (бесплатно, OSS)
- **Premium** — Billing, Marketplace, LMS, Revenue (подписка)
- **Cloud** — managed хостинг
- **Self-hosted** — Tribe Core, свой сервер

## Технически

- Статический SPA (Astro / Next.js)
- Маршруты: `/`, `/products/colive`, `/products/cospace`, `/pricing`, `/blog`, `/docs`
- SEO-оптимизирован
- Мультиязычность (русский, английский, испанский)
