# Делегирование

Делегируйте право голоса доверенным участникам. Ликвидная демократия для управления.

## Где найти

`/community/:id/delegation`

## Настройки

- **Макс. делегатов на участника (0 = без лимита)** (`max_delegates_per_member`) — целое, по умолчанию `0`
- **Разрешить самоделегирование** (`allow_self_delegation`) — да/нет, по умолчанию `False`

## Проверено e2e

- Пока нет e2e-сценария: это черновик, шаги стоит проверить вручную.

## Ограничения

- Модуль включает администратор сообщества; если он выключен, раздела нет в меню.
