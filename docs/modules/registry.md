# Модуль Registry

Реестр долей, владения, распределения.

## Сущности

- **Share** — доля участника в общем ресурсе
- **RegistryEntry** — запись реестра (участник, доля, статус)

## Actions

| Action | Описание |
|---|---|
| `register_share` | Зарегистрировать долю |
| `transfer_share` | Передать долю |
| `get_registry` | Получить реестр |

## Примеры для кейсов

| Продукт | Использование |
|---|---|
| **CoSettle** | Доли в земельном участке, строении |
| **CoOper** | Паевые взносы, распределение товаров |

## Связи

- С [Treasury](treasury.md) — учёт паевых взносов
- С [Proposals](proposals.md) — голосование пропорционально долям
