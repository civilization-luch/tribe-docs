# Модуль Content

Афиша, объявления, обсуждения, мероприятия.

## Сущности

- **Post** — публикация (анонс, объявление, новость)
- **Event** — мероприятие (дата, время, место, регистрация)
- **Comment** — комментарий/обсуждение
- **Category** — категория (афиша, бытовое, важное)

## Actions

| Action | Описание |
|---|---|
| `create_post` | Создать публикацию |
| `create_event` | Анонсировать мероприятие |
| `register_event` | Записаться на мероприятие |
| `comment` | Написать комментарий |
| `pin` | Закрепить |
| `archive` | Архивировать |

## Типы мероприятий

- Ужин / завтрак вместе
- Киновечер
- Языковой обмен
- Йога / спорт
- Воркшоп
- Хакатон / работа вместе
- Экскурсия / выезд

## Примеры для кейсов

| Продукт | Контент и мероприятия |
|---|---|
| **CoLive** | Афиша вечеринок, бытовые объявления, соседские обсуждения |
| **CoSpace** | Расписание классов, анонсы ивентов, отзывы на инструкторов |
| **CoSettle** | Собрания поселения, гайды по переезду, доски с объявлениями |
| **CoGuild** | Учебные материалы, анонсы курсов, портфолио проектов |
| **CoOper** | Каталог товаров для закупок, новости, обсуждение поставщиков |
