# Модуль Documents

Договоры, акты, правила дома, электронная подпись.

## Сущности

- **Document** — документ (договор, акт, правило, протокол)
- **Template** — шаблон документа
- **Signature** — подпись участника (простая / ЭЦП)
- **DocumentFlow** — статус документа (черновик → подписание → архив)

## Actions

| Action | Описание |
|---|---|
| `create_document` | Создать документ из шаблона |
| `sign` | Подписать |
| `get_template` | Получить шаблон |
| `archive` | Архивировать |
| `get_history` | История версий |

## Типы документов

| Тип | Назначение |
|---|---|
| Договор заезда | Соглашение с резидентом |
| Акт приёма-передачи | Состояние комнаты при заезде/выезде |
| Правила дома | Поведение, тишина, гости |
| Протокол собрания | Результаты голосования |
| Акт выезда | Закрытие обязательств |

## Шаблоны по регионам
