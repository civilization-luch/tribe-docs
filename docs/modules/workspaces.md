# Задачи

Задачи и этапы сообщества, сгруппированные в пространства.

## Где найти

`/community/:id/workspaces`

## Настройки

- **Тип задачи по умолчанию** (`default_issue_type`) — строка, по умолчанию `task`
- **Автоархив закрытых задач через, дн (0 = выкл)** (`auto_archive_closed_days`) — целое, по умолчанию `0`
- **Разрешить участникам создавать пространства** (`allow_member_workspaces`) — да/нет, по умолчанию `True`

## Проверено e2e

- Пока нет e2e-сценария.

## Ограничения

- Модуль включает администратор сообщества; если он выключен, раздела нет в меню.
