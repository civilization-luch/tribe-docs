# Модуль Billing

Платежи, подписки, сплит коммуналки.

## Сущности

- **Subscription** — периодический платёж (ежемесячный взнос)
- **Invoice** — счёт на оплату
- **Payment** — проведённый платёж
- **Split** — распределение коммунальных платежей между жильцами
- **Transaction** — движение средств (пополнение, списание, перевод)

## Actions

| Action | Описание |
|---|---|
| `create_subscription` | Создать подписку |
| `cancel_subscription` | Отменить подписку |
| `generate_invoice` | Сформировать счёт |
| `pay` | Оплатить |
| `split_utility` | Разделить коммуналку |
| `top_up` | Пополнить баланс |
| `withdraw` | Вывести средства |
| `transfer` | Перевести между счетами |
| `get_history` | История операций |

## Региональные настройки

| Регион | Валюта | Платёжные системы |
|---|---|---|
| Казахстан | KZT | Kaspi Pay, карты |
| Вьетнам | VND | Местные банки |
| Парагвай | PYG | Банковские переводы |
