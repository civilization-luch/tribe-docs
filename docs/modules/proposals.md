# Модуль Proposals

Голосования, предложения, коллективные решения.

## Сущности

- **Proposal** — предложение (тема, описание, варианты)
- **Vote** — голос участника
- **Ballot** — бюллетень с результатами

## Actions

| Action | Описание |
|---|---|
| `create_proposal` | Создать предложение |
| `vote` | Проголосовать |
| `delegate` | Делегировать голос |
| `close_proposal` | Закрыть голосование |
| `get_results` | Результаты |

## Типы голосований

- За/Против/Воздержался
- Выбор варианта (A/B/C)
- Рейтинг (1–5)
- Открытое / Анонимное

## Темы для коливинга

- Закупка (новая кофемашина, посудомойка)
- Изменение правил дома
- Утверждение нового резидента (после испытательного срока)
- Бюджет мероприятия
- Выбор ответственного за закупки

## Кворум и правила

- % участников для кворума
- % голосов для принятия
- Срок голосования (24ч / 48ч / 7 дней)
- Право вето у управляющего

## Связи

- С [Treasury](treasury.md) — голосование по бюджету
- С [Membership](membership.md) — кто имеет право голоса
- С [Reputation](reputation.md) — взвешенное голосование по репутации
