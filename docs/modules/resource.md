# Ресурсы

Реестр ресурсов: каталог, категоризация и управление ресурсами сообщества, включая землю.

## Где найти

`/community/:id/resources`

## Настройки

- **Требовать одобрение** (`require_approval`) — да/нет, по умолчанию `False`
- **Разрешить архивацию** (`allow_archive`) — да/нет, по умолчанию `True`
- **Категория по умолчанию** (`default_category`) — строка, по умолчанию `general`

## Проверено e2e

- Пока нет e2e-сценария: это черновик, шаги стоит проверить вручную.

## Ограничения

- Модуль включает администратор сообщества; если он выключен, раздела нет в меню.
