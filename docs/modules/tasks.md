# Модуль Tasks

Дежурства, обязанности, уборка, напоминания.

## Сущности

- **Task** — задача (что, кто, когда)
- **Duty** — регулярное дежурство (ротация)
- **DutyRoster** — график дежурств
- **Reminder** — напоминание

## Actions

| Action | Описание |
|---|---|
| `create_task` | Создать задачу |
| `assign` | Назначить ответственного |
| `complete` | Отметить выполнение |
| `create_duty` | Создать дежурство |
| `rotate_duty` | Сменить дежурного |
| `get_roster` | График дежурств |
| `remind` | Отправить напоминание |

## Типы задач

- Уборка (кухня, коридор, санузел)
- Вынос мусора
- Полив растений
- Проверка запасов (туалетная бумага, вода)
- Встреча новых жильцов
- Организация мероприятий

## Примеры для кейсов

| Продукт | Типы задач |
|---|---|
| **CoLive** | Уборка, вынос мусора, встреча гостей, дежурства по кухне |
| **CoSpace** | Подготовка зала к классу, встреча участников, уборка после ивента |
| **CoSettle** | Стройка, благоустройство территории, дороги, общие дежурства |
| **CoGuild** | Проектные задачи, хакатоны, домашки, код-ревью |
| **CoOper** | Закупки, распределение товаров, инвентаризация |
