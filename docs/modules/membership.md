# Модуль Membership

Управление участниками сообщества: заявки, статусы, профили.

## Сущности

- **Participant** — участник сообщества (резидент, арендатор, гость, управляющий)
- **Application** — заявка на вступление
- **Profile** — публичный профиль (имя, аватар, bio, интересы)

## Actions

| Action | Описание |
|---|---|
| `apply` | Подать заявку |
| `approve` | Одобрить заявку |
| `reject` | Отклонить заявку |
| `set_status` | Сменить статус (resident/guest/admin/etc) |
| `suspend` | Заморозить участие |
| `reinstate` | Восстановить |
| `exit` | Выйти из сообщества |
| `ban` | Заблокировать |

## Настройки

- Режим приёма (open / approval / probation / vouching / invite)
- Требуется поручитель (да/нет)
- Пробный период (дней)
- Голосование при приёме (да/нет, %)

## Примеры для кейсов

| Продукт | Типы участников |
|---|---|
| **CoLive** | Резидент, коммерческий арендатор, гость, управляющий, кандидат |
| **CoSpace** | Инструктор, участник сообщества, гость класса, админ пространства |
| **CoSettle** | Пайщик (владеет долей), резидент поселения, кандидат, управляющий |
| **CoGuild** | Эксперт (мастер), ментор, ученик, гость, админ |
| **CoOper** | Пайщик (член кооператива), ассоциированный член, правление |
