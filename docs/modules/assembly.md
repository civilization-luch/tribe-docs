# Собрания

Собрания сообщества с повесткой, протоколом и учётом посещаемости.

## Где найти

`/community/:id/assemblies`

## Настройки

- **Кворум, %** (`quorum_percentage`) — целое, по умолчанию `50`
- **Длительность по умолчанию, мин** (`default_duration_minutes`) — целое, по умолчанию `60`

## Проверено e2e

- Пока нет e2e-сценария: это черновик, шаги стоит проверить вручную.

## Ограничения

- Модуль включает администратор сообщества; если он выключен, раздела нет в меню.
