# Целевой сбор

Целевые сборы средств. Автоматическое распределение в Казну и Реестр.

## Где найти

`/community/:id/fundraiser`

## Настройки

- **Валюта** (`default_currency`) — строка, по умолчанию `KZT`
- **Минимальная цель** (`min_goal`) — целое, по умолчанию `0`
- **Разрешить перевыполнение** (`allow_overfunding`) — да/нет, по умолчанию `True`
- **Закрывать при достижении цели** (`auto_close_on_goal`) — да/нет, по умолчанию `False`

## Проверено e2e

- Пока нет e2e-сценария.

## Ограничения

- Модуль включает администратор сообщества; если он выключен, раздела нет в меню.
