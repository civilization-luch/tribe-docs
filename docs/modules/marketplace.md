# Модуль Marketplace

Платформа для аренды комнат и услуг внутри и вне сообщества.

## Сущности

- **Listing** — объявление (комната, пространство, услуга)
- **Order** — заказ / бронь
- **Service** — услуга (описание, цена, исполнитель)
- **Review** — отзыв на объявление

## Actions

| Action | Описание |
|---|---|
| `create_listing` | Создать объявление |
| `publish_listing` | Опубликовать |
| `book` | Забронировать / заказать |
| `cancel_order` | Отменить заказ |
| `complete_order` | Подтвердить выполнение |
| `review` | Оставить отзыв |

## Типы объявлений

| Тип | Для кого | Пример |
|---|---|---|
| Room | Внешние / резиденты | Свободная комната на неделю |
| Space | Внешние | Коворкинг на день, лаунж на ивент |
| Service | Резиденты | Трансфер, клининг, экскурсия |
| Equipment | Резиденты | Аренда проектора, велосипеда |

## Настройки видимости

- Только для резидентов
- Для внешних пользователей (открытый рынок)
- Гибрид (скидка резидентам)

## Модель дохода

- Комиссия платформы с каждой сделки
- Платное продвижение объявлений

## Примеры для кейсов

| Продукт | Типы объявлений |
|---|---|
| **CoLive** | Аренда комнаты (выезд резидента), услуги соседей (трансфер, клининг) |
| **CoSpace** | Услуги инструкторов (разовые классы), аренда зала внешним |
| **CoSettle** | Стройка, транспорт, переводы, услуги между поселенцами |
| **CoGuild** | Фриланс-заказы, поиск команды на проект |
| **CoOper** | Товары кооператива (опт), услуги пайщиков |
