# Модуль LMS (Learning Management System)

Создание и продажа курсов внутри сообщества.

## Сущности

- **Course** — курс (название, описание, программа, цена)
- **Lesson** — урок (текст, видео, файлы)
- **Enrollment** — запись на курс
- **Certificate** — сертификат о прохождении
- **Instructor** — автор курса (резидент или управляющий)
- **Review** — отзыв на курс

## Actions

| Action | Описание |
|---|---|
| `create_course` | Создать курс |
| `publish_course` | Опубликовать |
| `enroll` | Записаться на курс |
| `complete_lesson` | Завершить урок |
| `complete_course` | Завершить курс |
| `issue_certificate` | Выдать сертификат |
| `review_course` | Оставить отзыв |

## Примеры курсов для коливинга

- Как открыть свой коливинг
- Управление сообществом и фасилитация
- Английский / казахский для резидентов
- Йога, медитация, здоровый образ жизни
- SMM и контент для коливинга

| Продукт | Примеры курсов |

| **CoLive** | «Как открыть коливинг», «Управление сообществом» |

## Модель дохода

- Курс платный — цена устанавливается автором
- Платформа берёт комиссию с продажи
- Можно комбинировать с подпиской сообщества
