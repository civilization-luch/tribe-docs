# Модуль Schedule

Расписание, события, бронирования слотов.

## Сущности

- **Event** — событие в расписании (дата, время, место)
- **Slot** — временной слот для бронирования

## Actions

| Action | Описание |
|---|---|
| `create_event` | Создать событие |
| `update_event` | Обновить событие |
| `delete_event` | Удалить событие |
| `book_slot` | Забронировать слот |

## Примеры для кейсов

| Продукт | Использование |
|---|---|
| **CoSpace** | Расписание мероприятий, классов, бронирование залов |
