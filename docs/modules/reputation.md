# Модуль Reputation

Рейтинг, уровни доверия, отзывы.

## Сущности

- **Score** — общий рейтинг участника (0–1000)
- **Level** — уровень (Новичок → Старожил → Легенда)
- **Review** — отзыв от соседа
- **Badge** — нашивка/достижение

## Actions

| Action | Описание |
|---|---|
| `get_score` | Получить рейтинг |
| `add_review` | Оставить отзыв |
| `give_badge` | Выдать нашивку |
| `get_level` | Получить уровень |

## Как начисляются баллы

| Действие | Баллы |
|---|---|
| Своевременная оплата | +10 |
| Выполнение дежурства | +5 |
| Участие в голосовании | +3 |
| Организация мероприятия | +15 |
| Отзыв от соседа | +1–10 |
| Просрочка платежа | −10 |
| Пропуск дежурства | −5 |

## Уровни

| Уровень | Порог | Описание |
|---|---|---|
| Новичок | 0 | Только заехал |
| Жилец | 100 | Освоился |
| Старожил | 300 | Знает всех |
| Лидер | 600 | Организует жизнь |
| Легенда | 1000 | Душа дома |

## Влияние репутации

- Вес голоса в голосованиях (опционально)
- Приоритет при бронировании популярных комнат
- Поручительство при заезде новых жильцов

## Примеры для кейсов

| Продукт | За что начисляется репутация |
|---|---|
| **CoLive** | Своевременная оплата, дежурства, помощь соседям |
| **CoSpace** | Качество классов, отзывы учеников, пунктуальность |
| **CoSettle** | Участие в стройке, волонтёрство, активность на собраниях |
| **CoGuild** | Прогресс ученика, качество менторства, вклад в проекты |
| **CoOper** | Добросовестность платежей, активность в закупках |
