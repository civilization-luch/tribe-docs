# Модуль Groups

Кто с кем внутри сообщества и чем эта коалиция владеет. Группа — не просто список людей: у неё есть мандат, роли, видимость и, если нужно, срок жизни.

## Сущности

- **Group** — контейнер людей внутри сообщества: команда, дом, комитет, комиссия.
  - `kind` — `standing` (постоянная) или `temporary` (временная, со сроком);
  - `goal` — зачем группа собрана (обязателен по смыслу для временной);
  - `ends_by` — срок, только для временной;
  - `archived_at` — момент закрытия; архивная группа доступна только на чтение;
  - `visibility` — `public` / `private` / `hidden`;
  - `phase` — `forming` / `active` / `performing` / `adjourning`;
  - `mandate` — договорённости: `purpose`, `in_scope`, `out_of_scope`, `decide`, `recommend`, `escalate_to`, `budget_limit`, `review_at`.
- **Mandate** — полномочия скоупа: какие действия разрешены и до какого момента (см. [Authority](../architecture/authority.md)). Для временной группы мандат ограничен `ends_by`.
- **GroupJoinRequest** — заявка на вступление, если в сообществе включено одобрение.

## Actions

| Action | Описание |
|---|---|
| `create_group` | Создать группу; для временной обязательны `ends_by` и `goal` |
| `update_group` | Изменить название, описание, тип, видимость, фазу, лимит, мандат |
| `join_group` | Вступить (с учётом настроек сообщества и видимости) |
| `request_join_group` | Подать заявку, если включено одобрение |
| `approve_join_request` / `reject_join_request` / `cancel_join_request` | Разбор заявок |
| `add_member` | Добавить участника лидером или ко-лидером |
| `leave_group` | Выйти из группы |
| `set_member_role` | Назначить `leader`, `co_leader` или `member` |
| `hot_swap_member` | Заменить участника другим с сохранением роли |
| `extend_group` | Продлить срок временной группы |
| `archive_group` | Закрыть группу: освободить ресурсы, оставить историю |
| `delete_group` | Удалить группу (жёстко, только без проектов и workspace) |

## Временные группы

Временная группа — это манёвр, а не институт. Отличия от постоянной:

| Ось | Постоянная | Временная |
|---|---|---|
| Срок | не задан | `ends_by` обязателен |
| Полномочия | бессрочный мандат сообщества | мандат с `valid_until = ends_by` |
| Истечение | не наступает | права пропадают в момент срока, без участия фонового процесса |
| Закрытие | удаление админом | архив с освобождением ресурсов |
| Продление | не нужно | `extend_group`; только вперёд и в пределах `max_ttl_days` |

**Что происходит при истечении срока:**

1. Мандат перестаёт действовать — проверки `authorize()` больше не дают прав, даже если фоновая задача не отработала.
2. Первое обращение к группе (любая мутация) архивирует её.
3. Фоновый скан раз в час сам архивирует просроченные и заранее (за `nudge_days_before` дней) напоминает лидерам.

**Что освобождается при архивации:**

| Ресурс | Поведение |
|---|---|
| Доступы к workspace | отзываются |
| Задачи, где группа исполнитель или watcher | исполнитель снимается, подписка убирается |
| Связи с проектами | убираются из collaborator-списков |
| Заявки на вступление | отменяются |
| Открытые голосования | закрываются со статусом `cancelled` |
| Заявки поддержки, адресованные группе | перенаправляются в общую очередь |
| Касса группы | операции запрещены, остаток остаётся на счёте до решения админа |
| Группа и её история | остаются в архиве, доступны только на чтение |

**Восстановление.** Просроченную, но ещё не архивную группу лидер может продлить сам. Архивную — только владелец или админ сообщества: `extend_group` восстановит группу и выдаст новый мандат.

## Настройки модуля

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `groups.allow_self_join` | `true` | Разрешено ли самостоятельное вступление |
| `groups.require_approval` | `false` | Нужно ли одобрение заявки |
| `groups.max_members_per_group` | `0` | Лимит участников, `0` — без лимита |
| `groups.temporary_enabled` | `true` | Разрешены ли временные группы в сообществе |
| `groups.default_ttl_days` | `14` | Срок временной группы, если дата не указана |
| `groups.max_ttl_days` | `180` | Максимальный срок, дальше продление отклоняется |
| `groups.nudge_days_before` | `3` | За сколько дней напомнить лидерам |

## Права

Проверки идут через `authorize(access, capability, scope)` (см. [Authority](../architecture/authority.md)), а не по роли в группе:

- `group.manage` — лидер, ко-лидер или админ сообщества (состав, настройки, архив);
- `group.participate` — любой участник группы;
- `content.view` — видимость: `public` видит сообщество, `private` — состав, `hidden` — только по прямой ссылке;
- остальные capabilities (`treasury.operate`, `support.handle`, `proposal.decide`, `project.manage`, `workspace.access`, `wallet.operate`, `guarantee.operate`) выдаются группе мандатом.

## Кейсы

| Кейс | Как выражается |
|---|---|
| Дом в коливинге | Постоянная группа: своя касса, дежурства, комнаты |
| Отдел или комитет | Постоянная группа с мандатом и `review_at` |
| Оргкомитет мероприятия | Временная группа на 2–3 недели |
| Стенд для диспута | Временная группа на срок разбора, создаётся процессом |
| Замена человека без простоя | `hot_swap_member`: роль переходит, работа не останавливается |
