# Модуль Treasury

Казна, бюджеты, финансовая прозрачность.

## Сущности

- **Fund** — фонд/касса (общий, резервный, на мероприятия)
- **Budget** — бюджет на период
- **Transaction** — приход/расход
- **Category** — статья расходов (коммуналка, ремонт, уборка, ивенты)
- **Balance** — баланс участника

## Actions

| Action | Описание |
|---|---|
| `create_fund` | Создать фонд |
| `deposit` | Пополнить казну |
| `withdraw` | Списать из казны |
| `set_budget` | Установить бюджет |
| `get_balance` | Баланс участника |
| `get_report` | Отчёт за период |
| `audit` | Аудит казны |

## Фонды

| Фонд | Назначение |
|---|---|
| Общий | Коммуналка, аренда, базовые расходы |
| Резервный | Непредвиденные траты |
| Мероприятия | Еда, декор, ивенты |
| Ремонт | Мебель, ремонт, обновления |

## Прозрачность

Все транзакции видны всем участникам сообщества (или группе дома). Участник может в любой момент посмотреть, куда пошли деньги.
