# CoLive — Платформа для управления коливингами

*Продукт экосистемы Tribe.*

---

## Концепция

CoLive — это платформа, которая превращает обычную аренду жилья в самоорганизующееся сообщество. Люди не просто снимают комнату — они становятся участниками с правами, обязанностями, репутацией и долей в общих доходах.

## Проблема

Коливинги сегодня управляются вручную: Telegram + Excel, договоры в PDF, платежи — напоминаниями. С ростом количества жильцов и домов это перестаёт работать:

- Нет единой базы жильцов и истории заездов
- Платежи, дежурства, мероприятия — всё вручную
- Непрозрачный бюджет: кто платит, кто должен
- Нет инструментов для самоорганизации и голосований
- Жильцы не вовлечены в жизнь дома

## Решение

Всё в одном месте: заезд, платежи, задачи, мероприятия, голосования, документы, репутация.

## Модули

| Модуль | Назначение |
|---|---|
| **Membership** | Заявки, статусы (резидент / гость / коммерческий), профили, история заездов |
| **Billing** | Автоматические подписки, сплит коммуналки, квитанции, напоминания |
| **Bookings** | Календарь комнат и мест, онлайн-бронирование, отчёт по загрузке |
| **Tasks** | Дежурства, уборка, назначение ответственных, напоминания, ротация |
| **Treasury** | Прозрачная казна: приход/расход, фонды, бюджеты, отчёты |
| **Content** | Афиша мероприятий, объявления, обсуждения |
| **Proposals** | Голосования по общим вопросам (закупки, правила, ремонт) |
| **Reputation** | Рейтинг жильцов, нашивки, уровни |
| **Documents** | Договоры заезда, акты приёма-передачи, правила дома |

Платные сервисы (вторая очередь):

| Модуль | Назначение |
|---|---|
| **LMS** | Создание и продажа курсов (например, «Как открыть свой коливинг») |
| **Marketplace** | Аренда комнат внешним, услуги резидентов, аренда пространств |
| **Revenue** | Автоматическое распределение доходов между участниками |

## Архитектура сообщества

Один бренд / маркетинг — несколько домов.

```
CoLive [сообщество]
  │
  ├── Дом (группа) — своя казна, задачи, комнаты
  ├── Дом (группа) — своя казна, задачи, комнаты
  └── Дом (группа) — своя казна, задачи, комнаты
```

- **Единый профиль жильца** — переезд между домами без перерегистрации
- **Общая афиша** — мероприятия для всех домов
- **Автономия** — у каждого дома свой бюджет и правила
- **Единый маркетинг** — один бренд, одна команда

## Модель участников

| Тип | Описание | Голос | Платежи |
|---|---|---|---|
| **Резидент** | Постоянный жилец, член сообщества | Да | Взносы + коммуналка |
| **Коммерческий арендатор** | Арендует без участия в жизни | Нет | Аренда по договору |
| **Гость** | Краткосрочное проживание (дни–недели) | Нет | Потарифно |
| **Управляющий** | Владелец или наёмный менеджер | Вето | — |
| **Кандидат** | Подал заявку, проходит отбор | Нет | — |

## Приём в сообщество

Гибкий процесс, настраивается под каждый дом:

```
Заявка → Одобрение управляющего → Испытательный срок 
→ Голосование резидентов → Полноценный резидент
```

Режимы: Open / Approval / Probation / Vouching / Invite.

## Экономика сообщества

### Доходы от сервисов

Платформа даёт коливингу три типа дохода поверх базовой аренды:

| Сервис | Суть |
|---|---|
| **Курсы** | Опытные резиденты или управляющие создают и продают курсы |
| **Аренда внешним** | Свободные комнаты сдаются внешним гостям через Marketplace |
| **Услуги резидентов** | Трансфер, экскурсии, клининг — резиденты зарабатывают друг для друга и для внешних |

### Распределение доходов

| Сервис | Кому | Резидентам дома | В казну |
|---|---|---|---|
| Курс | Автору — **75%** | **10%** | **15%** |
| Аренда комнаты (внешним) | — (актив дома) | **30%** | **70%** |
| Услуга резидента | Исполнителю — **80%** | **10%** | **10%** |
| Аренда пространства | — (актив дома) | **25%** | **75%** |

Распределение среди резидентов — по **взвешенной доле участия**: стаж, дежурства, голосования, платежи, репутация. Кто больше вкладывается — больше получает.

### Модель партнёрства

CoLive не продаёт подписку — мы входим как партнёр и зарабатываем вместе. Доля платформы — процент от новых доходов, которые платформа генерирует.

## Франчайзинг коливингов (зонтичная структура)

CoLive-сообщество может тиражироваться: материнский коливинг создаёт шаблон (правила, бренд, процессы), а дочерние сообщества разворачиваются по этому шаблону в новых локациях — городах, странах.

```
CoLive Global [материнское сообщество]
  │
  ├── CoLive Cambodia [дочернее] — локальная казна, команда, резиденты
  ├── CoLive Vietnam  [дочернее] — локальная казна, команда, резиденты
  └── CoLive Bali     [дочернее] — локальная казна, команда, резиденты
```

### Что наследуется

| Элемент | От родителя | Локально переопределяется |
|---|---|---|
| Бренд и визуал | Да | Логотип может иметь локальный вариант |
| Правила дома | Шаблон | Дополнения под локальную культуру |
| Роли (резидент, гость, управляющий) | Да | Можно добавить локальные |
| Документы (договор, акт) | Шаблон | Адаптация под местное право |
| Процесс заезда (испытательный срок, голосование) | Да | — |
| Модули платформы | Да (пресет CoLive) | — |
| Казна | Независимая | — |
| Бюджет и цены | — | Локально (аренда, коммуналка) |
| Состав участников | — | Независимый |

### Модель партнёрства (франшиза)

| Сторона | Что даёт | Что получает |
|---|---|---|
| **Материнский коливинг** | Бренд, ноу-хау, шаблоны, обучение, маркетинг | % от оборота дочернего (роялти) или паушальный взнос |
| **Дочерний коливинг** | Локальная недвижимость, команда, знание рынка | Готовая система, бренд, сообщество резидентов |
| **Резидент** | — | Может переезжать между локациями, репутация сохраняется |

### Переезд резидента между локациями

Резидент CoLive Cambodia может переехать в CoLive Vietnam без перерегистрации:
- Единый профиль (тот же User ID)
- Репутация и история сохраняются
- Членство в новом доме — через облегчённую процедуру (vouching от предыдущего управляющего)
- Реализуется через Federation Protocol (см. VISION.md)

### Технически

На платформе это реализуется через **Parent-связь** (VISION.md — вертикаль):
- Родитель определяет пресет, шаблоны, базовые правила
- Дочернее сообщество — самостоятельный инстанс с собственным Entity Store
- Federation Protocol обеспечивает обмен репутацией и профилями между ними
- При создании дочернего — клонируется конфигурация модулей родителя
