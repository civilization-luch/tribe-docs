# CoSettle — Платформа для совместных поселений

*Продукт экосистемы Tribe.*

---

## Концепция

CoSettle — это платформа для организации совместных поселений. Группа людей объединяется, чтобы купить землю, обустроить инфраструктуру и управлять поселением сообща. Особенно актуально для переселенцев в Латинскую Америку (Парагвай, Колумбия, Мексика и др.).

## Проблема

Переезд в одиночку: дорого, рискованно, социально изолированно. Аренда, адаптация, бюрократия — каждый вопрос решается в одиночку.

Групповой переезд даёт:
- Экономию на покупке земли (оптом дешевле)
- Совместные вложения в инфраструктуру
- Поддержку и сообщество на месте
- Коллективный найм юристов, строителей, переводчиков
- Безопасность в чужой стране

Но организация такого поселения — хаос: кто сколько внёс, как делить, какие правила, кто за что отвечает.

## Пример: Поселение релокантов в Парагвае

10–20 семей цифровых кочевников и релокантов решают переехать в Парагвай:

- **Формирование группы** — знакомство, обсуждение целей
- **Сбор средств** — каждый вносит долю в общий фонд
- **Поиск земли** — голосование: локация, бюджет, размер
- **Покупка** — юридическое оформление на всех
- **Деление участков** — кто сколько взял, с голосованием
- **Обустройство** — дороги, вода, свет, общий дом
- **Заселение** — резиденты управляют поселением сообща

То же применимо к: экопоселениям, кохаузингам, инвестиционным группам в землю.

## Модули

### Базовые

| Модуль | Назначение |
|---|---|
| **Membership** | Кандидаты, пайщики, резиденты, управляющие |
| **Registry** | Реестр участков, паёв, долей в земле |
| **Treasury** | Общий фонд (покупка земли, стройка, инфраструктура) |
| **Proposals** | Голосования: выбор земли, правила, бюджет |
| **Documents** | Договоры паевого участия, правовая адаптация под страну |
| **Tasks** | Стройка, обустройство, дежурства по территории |
| **Content** | Афиша собраний, мероприятия, общие обсуждения |
| **Reputation** | Вклад участника в жизнь поселения |

### Сервисы (монетизация)

| Модуль | Назначение |
|---|---|
| **Marketplace** | Услуги между поселенцами (стройка, транспорт, переводы) |
| **LMS** | Гайды по переезду, адаптации, оформлению документов |
| **Revenue** | Распределение доходов от общей инфраструктуры |

## Модель участников

| Тип | Описание | Голос |
|---|---|---|
| **Кандидат** | Изучает сообщество, не внёс долю | Нет |
| **Пайщик** | Внёс долю в землю/инфраструктуру | Да (пропорционально доле) |
| **Резидент** | Живёт в поселении | Да |
| **Управляющий** | Организует процессы, админ | Вето |

## Жизненный цикл поселения

```mermaid
graph LR
    A["Поиск группы"] --> B["Сбор паёв"]
    B --> C["Покупка земли"]

    D --> E["Инфраструктура"]
    E --> F["Заселение"]
    F --> G["Управление"]
    G --> A
```

## Экономика

### Доходы

| Сервис | Суть |
|---|---|
| **Вступительные паи** | Доля участника в покупке земли |
| **Инфраструктурные взносы** | На дороги, воду, свет |
| **Аренда общей инфры** | Гостевые дома, коворкинг, общий зал |
| **Услуги между соседями** | Строительство, транспорт, переводы |

### Распределение доходов от общих активов

| Сервис | В казну поселения |
|---|---|
| Аренда гостевого дома | **100%** |
| Аренда общего зала (внешним) | **100%** |
| Услуга поселенца (соседу) | 5% (комиссия платформы) |
| Продажа доли новому участнику | Доход пайщику |

## Региональная специфика

CoSettle адаптируется под страну проживания:

| Регион | Особенности |
|---|---|
| **Парагвай** | Земельное право, PYG, испанский, local notaries, визовые режимы |
| **Колумбия** | COP, местные банки, земельный кадастр |
| **Мексика** | MXN, ejido law (общинные земли), нотариусы |
| **Коста-Рика** | Теневые титулы, проверка собственности |

Шаблоны документов, процессы регистрации и юридические гайды создаются под каждый регион.
